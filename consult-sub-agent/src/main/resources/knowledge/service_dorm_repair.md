## 一句话摘要

宿舍设施出现故障（水电、空调、网络、门锁、家具等）可在线提交报修，后勤维修组通常在 1-3 个工作日内上门处理。

## 适用报修类型

| 设施类型 | 常见问题 | 优先级参考 |
|--------|--------|---------|
| 水电 | 停电、漏水、水管堵塞 | 高（影响基本生活） |
| 空调 | 不制冷/制热、漏水、异响 | 中高 |
| 网络 | 网线故障、路由器无信号 | 中 |
| 门锁 | 锁芯损坏、钥匙折断、电子门锁故障 | 高（影响安全） |
| 家具 | 床架、桌椅、衣柜损坏 | 低中 |
| 其他 | 窗户、灯具、暖气等 | 按实际情况 |

## 报修所需信息

- 用户 ID（userId）
- 宿舍楼名称和房间号（如：东二宿舍 302 室）
- 故障类型（如：空调不制冷）
- 故障描述（越详细越好）
- 是否影响安全或基本生活（如是，注明"紧急"）
- 方便维修人员上门的时间段（如：工作日下午）

## 报修步骤

1. 通过智能助手提交报修申请，填写上述信息
2. 系统生成报修记录编号
3. 后勤维修组接单，通常 1-3 个工作日内联系上门
4. 维修完成后，可通过记录编号查询处理结果
5. 如有问题可提交反馈评价

## 处理时限参考

| 问题类型 | 预计处理时限 |
|--------|----------|
| 漏水、停电等安全隐患 | 当天或次日 |
| 门锁损坏 | 当天 |
| 空调、网络故障 | 1-3 个工作日 |
| 家具损坏 | 3-5 个工作日 |
| 寒暑假期间 | 酌情延长 |

## 常见问题 FAQ

**Q: 报修了但很久没人上门怎么办？**
A: 可通过智能助手查询报修记录状态，或直接联系后勤服务中心催单，并提供记录编号。

**Q: 空调报修之后多久能修好？**
A: 一般故障 1-2 个工作日；如需更换零件，可能需要 3-5 个工作日。夏季高峰期（7-9 月）报修量大，等待时间可能稍长。

**Q: 夜间突发停电怎么办？**
A: 夜间突发停电属于紧急情况，应立即联系宿舍管理员（宿管）或拨打后勤紧急服务电话，不需要等到白天提交报修单。

**Q: 宿舍门锁坏了锁不上门怎么处理？**
A: 立即联系宿管，请求紧急处理；同时可通过智能助手提交报修，备注"紧急，门锁无法锁闭，影响安全"。

**Q: 自己损坏的设施可以报修吗？**
A: 人为损坏原则上由当事人承担维修费用，报修时如实说明情况，后勤会评估处理方式。公共设施自然老化损坏免费维修。

**Q: 网络时断时续，是报修还是联系运营商？**
A: 先尝试重启路由器；如仍无效，检查是否整栋楼都有问题（可询问舍友）。宿舍内网络设施属后勤管理范围，可通过报修渠道处理；如涉及运营商线路问题，后勤会协助联系。

**Q: 报修时需要本人在场吗？**
A: 维修人员上门时建议有人在场，以便确认故障位置。如无法在场，可提前与维修人员沟通，由宿管协助开门（需本人授权）。

**Q: 维修结果不满意怎么投诉？**
A: 可通过反馈系统提交投诉，选择"宿舍维修服务"类型，注明记录编号和不满意原因，后勤处会跟进处理。

## 注意事项

- 报修时描述越具体，维修人员越能提前准备工具和零件，处理更高效
- 涉及水电安全隐患（如漏电、明显漏水），报修同时应立即告知宿管
- 维修期间配合维修人员进行必要的测试，避免重复报修
