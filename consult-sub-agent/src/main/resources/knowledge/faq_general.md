本文档汇总校园智能服务助手的常见使用问题，以及找错窗口时的正确引导，帮助师生快速找到对应的服务部门。

## 系统使用 FAQ

**Q: 我问了问题，助手没有帮我解决，怎么办？**
A: 智能助手的能力范围包括：政策咨询、服务事项预约/办理、反馈投诉。以下情况建议直接联系相关部门：
- 涉及学籍档案变更、毕业审核等复杂学籍事务
- 需要现场核验原件或签字盖章
- 紧急安全事件（如突发疾病、火灾）

**Q: 助手回答不准确，我可以反馈吗？**
A: 可以，遇到不准确或不满意的回答，可以在对话中直接说"这个回答有问题"或"帮我反馈一下"，助手会记录并提交反馈。

**Q: 可以用语音输入吗？**
A: 目前系统支持文字输入，语音输入功能暂未上线。

**Q: 我的对话记录会保存多久？**
A: 当前对话记录在本次会话期间保留，长期偏好（如常用服务类型、时间偏好）会经用户授权后存入记忆系统，用于后续个性化服务。

## 常见找错窗口情况说明

**"我去教务处问转专业，被告知去学院，学院说去教务处"**
→ 正确路径：先在学院确认是否满足申请条件（辅导员 / 教务员），再到教务处提交正式申请。两者都需要，顺序是：学院 → 教务处。

**"我去校园卡中心问挂失，他们说让我先线上挂失"**
→ 正确路径：线上挂失（校园APP或官网，即时生效）→ 确认挂失成功后 → 到校园卡中心补办。线上挂失更快，不必等到窗口才挂失。

**"我想申请助学金，不知道找谁"**
→ 正确路径：第一步先找本班辅导员，辅导员会指导填表、提交学院汇总，然后由学院统一报学生工作处，不需要学生直接找学生工作处。

**"我选错课了想退，教务处说过期了"**
→ 退课必须在补退选阶段（开学后第1-2周）操作，超期无法退课，须完成修读或提交特殊情况审批申请。

**"我报修了一周了还没人来修"**
→ 可通过智能助手查询报修记录状态，或直接致电后勤服务中心提供记录编号催单，紧急安全隐患请联系宿管值班室。
